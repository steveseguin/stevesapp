Watch AI Work in Real-Time

See exactly what Claude Code, Codex, or OpenCode are doing on your machine. Monitor builds, catch errors early, and stay informed without interrupting your workflow.

Zero Configuration

No VPN setup, no port forwarding, no firewall rules. Just run the server and connect from anywhere using a simple token. Works behind NAT and corporate firewalls.

Peer-to-Peer Security

Direct encrypted connection between your devices using WebRTC. Your terminal data never touches third-party servers. Open source and auditable.

Mobile-First Design

Purpose-built phone interface with touch-friendly controls, virtual keyboard buttons for Ctrl+C, arrow keys, and more. Works great on iOS and Android.

Get Started in 60 Seconds

# Install and run
npx terminal-hub
# Or clone and run
git clone https://github.com/nicehash/terminal-hub
cd terminal-hub && npm install && npm start

The server displays your token on startup. Enter it below to connect, or scan the QR code on your phone.
